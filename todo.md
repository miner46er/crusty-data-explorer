### Narrow-window chrome, 2026-10-19

Operator's screenshot at ~621x634 logical showed hollow-box glyphs beside the folder rows and the connection state dot, the status bar painting over its own controls, the grid toolbar's filter labels interleaved with the action group, the third tab clipped past the window edge, and the editor tools off-screen. Reproduced on this machine at 640x640 (the sidebar takes 336px, so the right-hand panels get 292px) through `tests/frames.rs::narrow_window_chrome_stays_clear` and `tests/glyph_set.rs`, both red at HEAD.

Mechanism, from node rects and rendered pixels: egui's right-to-left sub-layouts reserve no width, so the status bar and the grid toolbar painted over content already placed; plain left-to-right rows overflow the window (tabs, editor toolbar); and U+25CF/U+25CB/U+25CC/U+25B8/U+25BE/U+25B2/U+25BC/U+2192/U+2713/U+2715 are absent from the embedded font stack, so epaint painted its U+25FB replacement box.

Fix, one commit per unit: `measure chrome row widths before drawing them` adds `src/ui/fit.rs` (pure width arithmetic: `text_w`, `button_w`, `menu_w`, `elide`, `Budget`, `overflow_menu`, `spill`, measured against real widget rects in its own tests); `keep the status bar labels inside their row` reserves the three controls first and elides both labels; `give the results toolbar a second row when one cannot hold it` packs the five actions left to right with the tail behind one `…` menu, drawn through the same function as the inline row; `move the editor tools to their own row when they do not fit` keeps the combo, Run/Cancel, Explain, and the hint on row 1 and packs Save, the transaction block, Complete, Format, and Find on row 2; `wrap the tab strip instead of clipping it` (a hidden-bar ScrollArea was measured and a plain wheel does not scroll it); `paint the connection state dots and use glyphs the fonts carry` replaces the glyph-in-a-string dots with a painted disc, ring, or half-filled disc from one state value, and moves the folder arrows, sort marks, reference arrows, saved-rows check, and remove buttons onto glyphs the stack carries; `assert the wide chrome keeps today's shape` pins the wide layout in `tests/frames.rs::wide_layout_unchanged`.
